# Handover · Boost Air

Versión publicada del programa de **handover de turno** de Boost Air.

- **`Instalar-Handover.exe`** — instalador para Windows. Es el que se envía a las bases.
- `Handover.html` y `version.json` — la versión actual. Los programas de las bases la comprueban
  y se actualizan solos desde aquí; no hay que hacer nada en ellas.

Este repositorio lo actualiza automáticamente la publicación de cada versión: no se edita a mano.
